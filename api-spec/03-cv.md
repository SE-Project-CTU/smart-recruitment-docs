# CV & Template API

## Group Summary

Nhóm API quản lý template và CV của Candidate. Dữ liệu chính liên quan đến `CV_TEMPLATE`, `CV`, `CV_VERSION` và file PDF qua `MEDIA_FILE`. `CV_EMBEDDING` được AI service tạo và cập nhật bất đồng bộ; client không được ghi trực tiếp vector embedding.

## API List

| #   | API                           | Method & Path                               | Roles                                 |
| --- | ----------------------------- | ------------------------------------------- | ------------------------------------- |
| 1   | Liệt kê template CV           | `GET /api/v1/cv-templates`                  | Public                                |
| 2   | Xem template CV               | `GET /api/v1/cv-templates/{id}`             | Public                                |
| 3   | Tạo CV                        | `POST /api/v1/cvs`                          | Candidate                             |
| 4   | Liệt kê CV của tôi            | `GET /api/v1/cvs`                           | Candidate                             |
| 5   | Xem CV                        | `GET /api/v1/cvs/{id}`                      | Owner, authorized Recruiter           |
| 6   | Cập nhật CV                   | `PATCH /api/v1/cvs/{id}`                    | Candidate Owner                       |
| 7   | Xóa CV                        | `DELETE /api/v1/cvs/{id}`                   | Candidate Owner                       |
| 8   | Lưu thay đổi (Tạo version CV) | `POST /api/v1/cvs/{id}/versions`            | Candidate Owner                       |
| 9   | Liệt kê version CV            | `GET /api/v1/cvs/{id}/versions`             | Candidate Owner, authorized Recruiter |
| 10  | Xem version CV                | `GET /api/v1/cvs/{id}/versions/{versionId}` | Candidate Owner, authorized Recruiter |
| 11  | Xuất CV PDF                   | `POST /api/v1/cvs/{id}/export/pdf`          | Candidate Owner                       |
| 12  | Đổi trạng thái Public/Private | `PATCH /api/v1/cvs/{id}/visibility`         | Candidate Owner                       |

## Shared Rules

- Base URL: `/api/v1`.
- Endpoint protected yêu cầu `Authorization: Bearer <access-token>` và `X-Correlation-ID` là UUID.
- `id`, `templateId`, `versionId` là UUID.
- **Kiến trúc Template & Độc lập Bố cục:**
  - `CV_TEMPLATE` lưu trữ blueprint/mẫu khởi tạo: mã `code` (dùng để Frontend mapping tới component renderer, ví dụ: `harvard`, `modern_two_column`), `default_layout` (JSONB), `default_content` (JSONB), `default_presentation` (JSONB) và `version`.
  - Khi tạo CV (`POST /api/v1/cvs`), với mỗi field mà client không truyền, hệ thống tự động copy từ template tương ứng: `default_layout` → `CV.layout`, `default_content` → `CV.content`, `default_presentation` → `CV.presentation`. Sau khi tạo, các field này là bản sao độc lập — người dùng có thể tùy biến tự do mà không ảnh hưởng đến template mẫu.
  - `CV.content` chỉ chứa dữ liệu thông tin ứng viên theo [cv_content_schema.json](../diagrams/model/cv_content_schema.json); tuyệt đối không chứa thông tin phụ thuộc bố cục vật lý (như `sidebar`, `main`, `column`, `grid`).
  - `CV.layout` chứa trạng thái phân bổ sections vào các vùng bố cục theo [cv_layout_schema.json](../diagrams/model/cv_layout_schema.json).
  - `CV.presentation` chứa cấu hình visual styles (font, màu sắc, khoảng cách) theo [cv_presentation_schema.json](../diagrams/model/cv_presentation_schema.json).
  - Mỗi khi tạo version (`CV_VERSION`), hệ thống lưu trữ trọn vẹn snapshot của `content`, `layout` và `presentation`.
- Chỉ Candidate sở hữu CV mới được tạo, sửa, xóa, export hoặc đổi visibility.
- CV `Private` chỉ owner được xem; CV `Public` có thể được xem trong các luồng được phép.
- Tất cả response JSON dùng envelope `data`, `meta`, `correlationId`; lỗi dùng `error`, `correlationId` theo [README.md](README.md).

<summary><strong>API 1: List CV Templates</strong></summary>

### Title & Summary

**Liệt kê template CV đang hoạt động**

Trả về các template CV mà Candidate có thể sử dụng, kèm mã `code`, thumbnail, `defaultLayout`, `defaultContent` và `defaultPresentation` khởi tạo.

### Method & Path

```http
GET /api/v1/cv-templates
```

### Authentication & Authorization

- Public endpoint, không yêu cầu Access Token.
- Chỉ trả về template có `is_active = true`.

### Headers

| Header             | Required | DataType | Validation Rules           |
| ------------------ | -------: | -------- | -------------------------- |

| `pageSize` |       No | Integer  | Mặc định 20; từ 1 đến 100.                       |

<summary><strong>API 4: List My CVs</strong></summary>

### Title & Summary

**Liệt kê CV của Candidate hiện tại**

Trả về danh sách CV do Candidate hiện tại sở hữu, bao gồm thông tin template, version hiện hành và trạng thái Public/Private.

### Method & Path

```http
GET /api/v1/cvs
```

### Authentication & Authorization

- Yêu cầu Access Token hợp lệ.
- Chỉ role `Candidate` được xem danh sách của chính mình.

### Headers

| Header             | Required | DataType | Validation Rules           |
| ------------------ | -------: | -------- | -------------------------- |
| `Authorization`    |      Yes | String   | `Bearer <access-token>`.   |
| `Accept`           |      Yes | String   | Hỗ trợ `application/json`. |
| `X-Correlation-ID` |      Yes | UUID     | UUID hợp lệ.               |

### Request Parameters / Body

| Parameter  | Required | DataType | Validation Rules              |
| ---------- | -------: | -------- | ----------------------------- |
| `page`     |       No | Integer  | Mặc định 1; từ 1 trở lên.     |
| `pageSize` |       No | Integer  | Mặc định 20; từ 1 đến 100.    |
| `isPublic` |       No | Boolean  | Lọc theo trạng thái hiển thị. |
| `language` |       No | String   | ISO 639-1.                    |

Không có request body.

### Response Status Codes

| Status | Meaning               | Condition                  |
| -----: | --------------------- | -------------------------- |
|  `200` | OK                    | Trả về danh sách CV.       |
|  `400` | Bad Request           | Query không hợp lệ.        |

**Xem chi tiết CV**

```http
GET /api/v1/cvs/{id}
```

- Yêu cầu Access Token khi xem CV Private.

### Request Parameters / Body

| Parameter | Required | DataType | Validation Rules |
| --------- | -------: | -------- | ---------------- |
| `id`      |      Yes | UUID     | CV phải tồn tại. |

Không có request body.

| Status | Meaning               | Condition                     |

<summary><strong>API 6: Update CV</strong></summary>

### Title & Summary

**Cập nhật nội dung, bố cục và presentation của CV**

Cho phép owner cập nhật CV (nội dung, bố cục kéo thả, visual styles). Cập nhật trực tiếp trên bản ghi `CV` và không tự động thay đổi `CV_TEMPLATE`.

### Method & Path

```http
PATCH /api/v1/cvs/{id}
```

### Authentication & Authorization

- Yêu cầu Access Token hợp lệ.
- Chỉ Candidate sở hữu CV được gọi.

### Headers

| Header             | Required | DataType | Validation Rules         |
| ------------------ | -------: | -------- | ------------------------ |
| `Authorization`    |      Yes | String   | `Bearer <access-token>`. |
| `Content-Type`     |      Yes | String   | `application/json`.      |
| `X-Correlation-ID` |      Yes | UUID     | UUID hợp lệ.             |

### Request Parameters / Body

| Field          | Required | DataType    | Validation Rules             |
| -------------- | -------: | ----------- | ---------------------------- |
| `id`           |      Yes | UUID        | CV phải thuộc user hiện tại. |
| `title`        |       No | String      | Từ 1 đến 150 ký tự.          |

<summary><strong>API 11: Export CV as PDF</strong></summary>

### Title & Summary

**Xuất CV thành file PDF**

Render version hiện hành của CV thành PDF, lưu file vào storage và tạo metadata `MEDIA_FILE` thuộc owner. Nếu xử lý bất đồng bộ, server trả `202` cùng `jobId`.

### Method & Path

```http
POST /api/v1/cvs/{id}/export/pdf
```

### Authentication & Authorization

- Yêu cầu Access Token hợp lệ.
- Chỉ Candidate sở hữu CV được gọi.

### Headers

| Header             | Required | DataType | Validation Rules           |
| ------------------ | -------: | -------- | -------------------------- |
| `Authorization`    |      Yes | String   | `Bearer <access-token>`.   |
| `Content-Type`     |      Yes | String   | `application/json`.        |
| `Accept`           |      Yes | String   | Hỗ trợ `application/json`. |
| `X-Correlation-ID` |      Yes | UUID     | UUID hợp lệ.               |

### Request Parameters / Body

| Field       | Required | DataType | Validation Rules                                             |
| ----------- | -------: | -------- | ------------------------------------------------------------ |
| `id`        |      Yes | UUID     | CV thuộc user hiện tại.                                      |
| `versionId` |       No | UUID     | Version cần xuất (mặc định xuất version mới nhất hiện hành). |

### Response Status Codes

| Status | Meaning               | Condition                     |
| -----: | --------------------- | ----------------------------- |
|  `200` | OK                    | PDF được tạo đồng bộ.         |
|  `202` | Accepted              | Tác vụ render đã được queue.  |
|  `400` | Bad Request           | Body hoặc UUID sai format.    |
|  `401` | Unauthorized          | Access Token không hợp lệ.    |
|  `403` | Forbidden             | User không phải owner.        |
|  `404` | Not Found             | CV/version không tồn tại.     |
|  `422` | Unprocessable Entity  | Nội dung CV không thể render. |
|  `500` | Internal Server Error | Lỗi render hoặc storage.      |

### Example Request

```json
{
  "versionId": "0d55e7ee-44f4-4d30-a65c-d9c5af5cf6c8"
}
```

### Example Success Response

```json
{
  "data": {
    "mediaFileId": "c7a8ad8c-d7d9-42b3-b7db-61b6be18d1cb",
    "fileName": "nguyen-van-a-backend-cv.pdf",
    "fileUrl": "https://cdn.smarthire.example/cv/c7a8ad8c.pdf",
    "fileType": "application/pdf",
    "fileSize": 245760,
    "versionId": "0d55e7ee-44f4-4d30-a65c-d9c5af5cf6c8"
  },
  "meta": {},
  "correlationId": "5f1c0d68-9a3f-4c85-bf50-4a7c17c1e2af"
}
```

<summary><strong>API 12: Update CV Visibility</strong></summary>

### Title & Summary

**Chuyển trạng thái Public/Private của CV**

Cho phép Candidate owner bật hoặc tắt trạng thái công khai của từng CV. Mặc định CV mới là `Private`.

### Method & Path

```http
PATCH /api/v1/cvs/{id}/visibility
```

### Authentication & Authorization

- Yêu cầu Access Token hợp lệ.
- Chỉ Candidate sở hữu CV được gọi.

### Headers

| Header             | Required | DataType | Validation Rules         |
| ------------------ | -------: | -------- | ------------------------ |
| `Authorization`    |      Yes | String   | `Bearer <access-token>`. |
| `Content-Type`     |      Yes | String   | `application/json`.      |
| `X-Correlation-ID` |      Yes | UUID     | UUID hợp lệ.             |

### Request Parameters / Body

| Field      | Required | DataType | Validation Rules              |
| ---------- | -------: | -------- | ----------------------------- |
| `id`       |      Yes | UUID     | CV thuộc user hiện tại.       |
| `isPublic` |      Yes | Boolean  | Chỉ nhận `true` hoặc `false`. |

### Response Status Codes

| Status | Meaning               | Condition                       |
| -----: | --------------------- | ------------------------------- |
|  `200` | OK                    | Cập nhật visibility thành công. |
|  `400` | Bad Request           | UUID hoặc JSON sai format.      |
|  `401` | Unauthorized          | Access Token không hợp lệ.      |
|  `403` | Forbidden             | User không phải owner.          |
|  `404` | Not Found             | CV không tồn tại.               |
|  `422` | Unprocessable Entity  | `isPublic` không phải boolean.  |
|  `500` | Internal Server Error | Lỗi cập nhật CV.                |

### Example Request

```json
{
  "isPublic": true
}
```

### Example Success Response

```json
{
  "data": {
    "id": "b3e6ae75-3264-47ec-94c6-e2f1f7a70c9d",
    "isPublic": true,
    "updatedAt": "2026-09-29T13:00:00Z"
  },
  "meta": {},
  "correlationId": "5f1c0d68-9a3f-4c85-bf50-4a7c17c1e2af"
}
```
