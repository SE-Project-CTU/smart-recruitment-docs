# CV & Template API

## Group Summary

Quản lý `CV_TEMPLATE`, `CV`, `CV_VERSION` và file PDF liên quan qua `MEDIA_FILE`.

## Planned API Scope

- Liệt kê và xem template CV đang hoạt động.
- Tạo, cập nhật, xóa và xem danh sách CV của Candidate.
- Lưu nội dung `content` và cấu hình trình bày `presentation` dạng JSON.
- Tạo, xem và khôi phục phiên bản CV.
- Xuất CV thành PDF.
- Chuyển trạng thái Public/Private.

> Endpoint chi tiết sẽ được bổ sung theo cùng structure trong `README.md`.
