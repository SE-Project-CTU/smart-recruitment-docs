# CV & Template API

## Group Summary

Nhóm API quản lý template và CV của Candidate. Dữ liệu chính liên quan đến `CV_TEMPLATE`, `CV`, `CV_VERSION` và file PDF qua `MEDIA_FILE`. `CV_EMBEDDING` được AI service tạo và cập nhật bất đồng bộ; client không được ghi trực tiếp vector embedding.

## API List

| #   | API                           | Method & Path                                        | Roles                                 |
| --- | ----------------------------- | ---------------------------------------------------- | ------------------------------------- |
| 1   | Liệt kê template CV           | `GET /api/v1/cv-templates`                           | Public                                |
| 2   | Xem template CV               | `GET /api/v1/cv-templates/{id}`                      | Public                                |
| 3   | Tạo CV                        | `POST /api/v1/cvs`                                   | Candidate                             |
| 4   | Liệt kê CV của tôi            | `GET /api/v1/cvs`                                    | Candidate                             |
| 5   | Xem CV                        | `GET /api/v1/cvs/{id}`                               | Owner, authorized Recruiter           |
| 6   | Cập nhật CV                   | `PATCH /api/v1/cvs/{id}`                             | Candidate Owner                       |
| 7   | Xóa CV                        | `DELETE /api/v1/cvs/{id}`                            | Candidate Owner                       |
| 8   | Lưu thay đổi (Tạo version CV) | `POST /api/v1/cvs/{id}/versions`                     | Candidate Owner                       |
| 9   | Liệt kê version CV            | `GET /api/v1/cvs/{id}/versions`                      | Candidate Owner, authorized Recruiter |
| 10  | Xem version CV                | `GET /api/v1/cvs/{id}/versions/{versionId}`          | Candidate Owner, authorized Recruiter |
| 11  | Xuất CV PDF                   | `POST /api/v1/cvs/{id}/export/pdf`                   | Candidate Owner                       |
| 12  | Đổi trạng thái Public/Private | `PATCH /api/v1/cvs/{id}/visibility`                  | Candidate Owner                       |

## Shared Rules

- Base URL: `/api/v1`.
- Endpoint protected yêu cầu `Authorization: Bearer <access-token>` và `X-Correlation-ID` là UUID.
- `id`, `templateId`, `versionId` là UUID.
- Chỉ Candidate sở hữu CV mới được tạo, sửa, xóa, export hoặc đổi visibility.
- CV `Private` chỉ owner được xem; CV `Public` có thể được xem trong các luồng được phép, nhưng dữ liệu private không được lộ qua API public.
- `content` phải tuân theo [cv_content_schema.json](../diagrams/model/cv_content_schema.json), gồm `metadata`, `profile`, `objective` và `sections`.
- `presentation` phải tuân theo [cv_presentation_schema.json](../diagrams/model/cv_presentation_schema.json), gồm `metadata` và `styles.global/fields`.
- `CV.language` phải trùng với `content.metadata.language`; `content.metadata.template_id` phải trùng template code mà server ánh xạ tới `CV.template_id`.
- `content.metadata.updated_at` và `presentation.metadata.updated_at` do server cập nhật theo ISO 8601 UTC.
- `language` dùng mã ISO 639-1, ví dụ `vi` hoặc `en`.
- Các section dạng danh sách dùng `{title, visible, items}`; `interests` và `additionalInfo` dùng `{title, visible, content}`.
- Các item trong section phải có `id` unique trong section. Tên field phải giữ nguyên schema, ví dụ `project_name`, `award_name`, `startDate` và `issueDate`.
- Không cho phép client gửi hoặc sửa `candidate_id`, `created_at`, `updated_at`, `version_number`.
- Tất cả response JSON dùng envelope `data`, `meta`, `correlationId`; lỗi dùng `error`, `correlationId` theo [README.md](README.md).
- `CV_EMBEDDING` được tạo bởi AI pipeline sau khi CV version được lưu; API CV chỉ có thể trả trạng thái embedding nếu cần.

<summary><strong>API 1: List CV Templates</strong></summary>

### Title & Summary

**Liệt kê template CV đang hoạt động**

Trả về các template CV mà Candidate có thể sử dụng, kèm thumbnail và URL cấu trúc template.

### Method & Path

```http
GET /api/v1/cv-templates
```

### Authentication & Authorization

- Public endpoint, không yêu cầu Access Token.
- Chỉ trả về template có `is_active = true`.

### Headers

| Header             | Required | DataType | Validation Rules           |
| ------------------ | -------: | -------- | -------------------------- |
| `Accept`           |      Yes | String   | Hỗ trợ `application/json`. |
| `X-Correlation-ID` |      Yes | UUID     | UUID hợp lệ.               |

### Request Parameters / Body

| Parameter  | Required | DataType | Validation Rules                         |
| ---------- | -------: | -------- | ---------------------------------------- |
| `page`     |       No | Integer  | Mặc định 1; từ 1 trở lên.                |
| `pageSize` |       No | Integer  | Mặc định 20; từ 1 đến 100.               |
| `search`   |       No | String   | Tối đa 100 ký tự; tìm theo tên template. |

Không có request body.

### Response Status Codes

| Status | Meaning               | Condition                  |
| -----: | --------------------- | -------------------------- |
|  `200` | OK                    | Trả về danh sách template. |
|  `400` | Bad Request           | Query không hợp lệ.        |
|  `500` | Internal Server Error | Lỗi truy vấn template.     |

### Example Success Response

```json

  ],

    "totalItems": 1,
    "totalPages": 1,
    "hasNextPage": false,
    "hasPreviousPage": false
```

<summary><strong>API 3: Create CV</strong></summary>

### Title & Summary

**Tạo CV mới**

Tạo CV thuộc Candidate hiện tại với template, nội dung và cấu hình trình bày được chọn. Server tạo version đầu tiên với `version_number = 1`.

### Method & Path

```http
POST /api/v1/cvs
```

### Authentication & Authorization

- Yêu cầu Access Token hợp lệ.
- Chỉ role `Candidate` được gọi.

### Headers

| Header             | Required | DataType | Validation Rules         |
| ------------------ | -------: | -------- | ------------------------ |
| `Authorization`    |      Yes | String   | `Bearer <access-token>`. |
| `Content-Type`     |      Yes | String   | `application/json`.      |
| `X-Correlation-ID` |      Yes | UUID     | UUID hợp lệ.             |

### Request Parameters / Body

| Field          | Required | DataType    | Validation Rules                                                                                                             |
| -------------- | -------: | ----------- | ---------------------------------------------------------------------------------------------------------------------------- |
| `templateId`   |      Yes | UUID        | Template tồn tại và `is_active = true`.                                                                                      |
| `title`        |      Yes | String      | Từ 1 đến 150 ký tự sau trim.                                                                                                 |
| `content`      |      Yes | JSON Object | Đúng `cv_content_schema.json`; bắt buộc `metadata`, `profile`, `objective`, `sections`, `profile.fullName`, `profile.email`. |
| `presentation` |      Yes | JSON Object | Đúng `cv_presentation_schema.json`; bắt buộc `metadata`, `styles.global` và `styles.fields`.                                 |
| `language`     |      Yes | String      | ISO 639-1, ví dụ `vi`, `en`.                                                                                                 |
| `isPublic`    |       No | Boolean     | Mặc định `false`.                                                                                                            |

### Response Status Codes

| Status | Meaning               | Condition                                           |
| -----: | --------------------- | --------------------------------------------------- |
|  `201` | Created               | Tạo CV và version đầu tiên thành công.              |
|  `400` | Bad Request           | JSON sai cú pháp.                                   |
|  `401` | Unauthorized          | Access Token thiếu hoặc không hợp lệ.               |
|  `403` | Forbidden             | User không có role Candidate.                       |
|  `404` | Not Found             | Template không tồn tại.                             |
|  `422` | Unprocessable Entity  | Content/presentation/language không đạt validation. |
|  `500` | Internal Server Error | Lỗi transaction tạo CV/version.                     |

<summary><strong>API 6: Update CV</strong></summary>

### Title & Summary

**Cập nhật nội dung và presentation của CV**

Cho phép owner cập nhật CV. Mỗi lần lưu thay đổi tạo một `CV_VERSION` mới, không ghi đè lịch sử cũ.

### Method & Path

```http
PATCH /api/v1/cvs/{id}
```

### Authentication & Authorization

- Yêu cầu Access Token hợp lệ.
- Chỉ Candidate sở hữu CV được gọi.

### Headers

| Header             | Required | DataType | Validation Rules         |
| ------------------ | -------: | -------- | ------------------------ |
| `Authorization`    |      Yes | String   | `Bearer <access-token>`. |
| `Content-Type`     |      Yes | String   | `application/json`.      |
| `X-Correlation-ID` |      Yes | UUID     | UUID hợp lệ.             |

### Request Parameters / Body

| Field          | Required | DataType    | Validation Rules             |
| -------------- | -------: | ----------- | ---------------------------- |
| `id`           |      Yes | UUID        | CV phải thuộc user hiện tại. |
| `title`        |       No | String      | Từ 1 đến 150 ký tự.          |
| `templateId`  |       No | UUID        | Template mới phải active.    |
| `content`      |       No | JSON Object | Đúng schema template.        |
| `presentation` |       No | JSON Object | Đúng schema presentation.    |
| `language`     |       No | String      | ISO 639-1.                   |

Phải gửi ít nhất một field cập nhật. Không cho phép cập nhật `candidate_id`, `is_public`, `created_at` trực tiếp ở endpoint này.

### Response Status Codes

| Status | Meaning               | Condition                                       |
| -----: | --------------------- | ----------------------------------------------- |
|  `200` | OK                    | Cập nhật CV và tạo version mới thành công.      |
|  `400` | Bad Request           | UUID hoặc JSON sai format.                      |
|  `401` | Unauthorized          | Access Token không hợp lệ.                      |
