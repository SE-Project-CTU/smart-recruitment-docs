# Administration API

## Group Summary

Quản trị `USER`, `ROLE`, `PERMISSION`, `ROLE_PERMISSION`, doanh nghiệp, tin tuyển dụng, danh mục ngành nghề/địa điểm và `CV_TEMPLATE`.

## Planned API Scope

- Duyệt hoặc từ chối doanh nghiệp và tin tuyển dụng.
- Khóa hoặc khôi phục tài khoản người dùng.
- Quản lý role, permission và mapping phân quyền.
- Quản lý nhóm ngành, ngành nghề, địa điểm và template CV.
- Xem dashboard thống kê vận hành.

> Tất cả endpoint trong nhóm này yêu cầu role `Admin`.
