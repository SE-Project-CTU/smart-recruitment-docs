# AI Assistant API

## Group Summary

Cung cấp các API tích hợp dịch vụ AI cho trợ lý viết CV, phân tích độ phù hợp và đề xuất việc làm; kết quả được lưu qua `AI_MATCH_RESULT` và `JOB_RECOMMENDATION`.

## Planned API Scope

- Gợi ý viết lại nội dung CV và bổ sung từ khóa.
- Phân tích semantic giữa CV version và job posting.
- Trả về điểm phù hợp, phân tích và khoảng trống kỹ năng.
- Tạo và truy vấn đề xuất việc làm cho Candidate.
- Xử lý timeout, lỗi upstream và bảo toàn dữ liệu người dùng.

> Endpoint chi tiết sẽ được bổ sung theo cùng structure trong `README.md`.
