# AI Assistant API

## Group Summary

Nhóm API tích hợp các dịch vụ trí tuệ nhân tạo (AI Services) cho trợ lý viết CV, phân tích & chấm điểm độ phù hợp giữa CV và mô tả công việc (JD), cùng tính năng tự động gợi ý việc làm thông minh cho Ứng viên. Kết quả xử lý AI được lưu trữ trong `AI_MATCH_RESULT` và `JOB_RECOMMENDATION`.

## API List

| #   | API | Method & Path | Resource | Roles |
| --- | --- | ------------- | -------- | ----- |
| 1   | Gợi ý & tối ưu hóa nội dung CV | `POST /api/v1/ai/cv/enhance` | Dynamic AI Service | Candidate |
| 2   | Phân tích & chấm điểm độ phù hợp | `POST /api/v1/ai/match-analysis` | `AI_MATCH_RESULT` | Candidate, Recruiter |
| 3   | Xem kết quả phân tích AI đơn ứng tuyển | `GET /api/v1/ai/applications/{applicationId}/match-result` | `AI_MATCH_RESULT` | Candidate, Recruiter |
| 4   | Danh sách việc làm gợi ý thông minh | `GET /api/v1/ai/recommendations` | `JOB_RECOMMENDATION` | Candidate |
| 5   | Yêu cầu làm mới gợi ý việc làm | `POST /api/v1/ai/recommendations/refresh` | `JOB_RECOMMENDATION` | Candidate |

## Shared Rules

- Base URL: `/api/v1`.
- Bắt buộc `Authorization: Bearer <access-token>` và `X-Correlation-ID` là UUID cho tất cả các endpoint.
- **Quy tắc xử lý sự cố & ngoại lệ AI (REQ-AI-6):**
  - Thời gian phản hồi tối đa của AI API gateway là 15 giây. Khi dịch vụ AI quá tải, phản hồi chậm hoặc ngắt kết nối, hệ thống trả về mã lỗi `503 Service Unavailable` hoặc `504 Gateway Timeout` với mã lỗi nghiệp vụ `AI_SERVICE_UNAVAILABLE`.
  - Thông báo lỗi trả về cho người dùng: *"Dịch vụ AI đang bận, vui lòng thử lại sau"*.
  - Toàn bộ dữ liệu người dùng đang biên soạn trên UI phải được giữ nguyên, không xóa hay ghi đè dữ liệu dở dang.
- Điểm số phù hợp (`score`) được chuẩn hóa theo thang điểm phần trăm từ `0.00` đến `100.00`.
- Response dùng `data`, `meta`, `correlationId`; lỗi dùng `error`, `correlationId` theo [README.md](README.md).

## ERD Response Mapping

| API field | ERD column | Resource |
| --- | --- | --- |
| `score` | `score` | `AI_MATCH_RESULT`, `JOB_RECOMMENDATION` |
| `analysis` / `missingSkills` | `analysis` | `AI_MATCH_RESULT` |
| `candidateId` / `jobId` | `candidate_id` / `job_id` | `JOB_RECOMMENDATION` |
| `generatedAt` | `generated_at` | `JOB_RECOMMENDATION` |

<summary><strong>API 1: Enhance CV Content</strong></summary>

### Title & Summary

**Trợ lý viết CV - Gợi ý từ ngữ & Tối ưu hóa nội dung**

Cho phép Ứng viên gửi một đoạn văn mô tả kinh nghiệm, dự án hoặc mục tiêu nghề nghiệp để AI viết lại chuyên nghiệp hơn, chuẩn hóa từ vựng và tự động đề xuất từ khóa ngành phù hợp.

### Method & Path

```http
POST /api/v1/ai/cv/enhance
```

### Authentication & Authorization

Candidate hoặc Recruiter với Access Token hợp lệ.

### Headers

`Authorization`, `Content-Type: application/json` và `X-Correlation-ID` UUID là bắt buộc.

### Request Parameters / Body

| Field | Required | DataType | Validation Rules |
| --- | ---: | --- | --- |
| `content` | Yes | String | 10 - 2000 ký tự. |
| `sectionType` | Yes | Enum | `WORK_EXPERIENCE`, `PROJECT`, `OBJECTIVE`, `SKILLS`, `SUMMARY`. |
| `targetJobTitle` | No | String | Tối đa 150 ký tự; ví dụ: "Senior Backend Developer". |
| `language` | No | String | Mặc định `vi`; hỗ trợ `vi`, `en`. |

### Response Status Codes

`200` thành công; `400` thiếu/sai body; `401` token sai; `422` validation; `503` AI bận/lỗi kết nối (`AI_SERVICE_UNAVAILABLE`).

### Example Request

```json
{
  "content": "Tôi làm công việc viết code API Nodejs cho cty khoảng 2 năm, sửa bug và tối ưu database.",
  "sectionType": "WORK_EXPERIENCE",
  "targetJobTitle": "Backend Engineer",
  "language": "vi"
}
```

### Example Success Response

```json
{
  "data": {
    "originalContent": "Tôi làm công việc viết code API Nodejs cho cty khoảng 2 năm, sửa bug và tối ưu database.",

    "suggestedKeywords": [
      "Node.js",
      "RESTful API",
      "Database Optimization",
      "Debugging",
      "Backend Development"
    ],
    "improvements": [
      "Sử dụng thuật ngữ chuyên môn chuẩn hóa thay cho cách nói thông thường.",
      "Nhấn mạnh kết quả hành động tối ưu hóa và xử lý sự cố."
    ]
  },
  "meta": {},
  "correlationId": "5f1c0d68-9a3f-4c85-bf50-4a7c17c1e2af"
```

<summary><strong>API 2: Analyze Match between CV and Job Posting</strong></summary>

### Title & Summary

**Phân tích & Chấm điểm độ phù hợp giữa CV và JD**

Thực hiện bóc tách ngữ nghĩa (Semantic Parsing), tính toán phần trăm phù hợp, xác định danh sách kỹ năng thiếu và đưa ra nhận xét chi tiết giúp Ứng viên hoặc Nhà tuyển dụng đánh giá độ tương thích.

### Method & Path

```http
POST /api/v1/ai/match-analysis
```

### Authentication & Authorization

Candidate hoặc Recruiter với Access Token hợp lệ.

### Headers

`Authorization`, `Content-Type: application/json` và `X-Correlation-ID` UUID là bắt buộc.

### Request Parameters / Body

| Field | Required | DataType | Validation Rules |
| --- | ---: | --- | --- |
| `cvId` | Conditional | UUID | Lấy phiên bản CV mới nhất nếu không truyền `cvVersionId`. |
| `jobId` | Yes | UUID | Tin tuyển dụng phải tồn tại. |

### Response Status Codes

`200` thành công; `400` sai body; `401` token sai; `404` CV hoặc Job không tồn tại; `503` AI bận (`AI_SERVICE_UNAVAILABLE`).

### Example Request

```json
{
  "cvVersionId": "d3b07384-d113-424a-a43d-045388c2ec11",
  "jobId": "c8b2f7a1-3c2e-4a7c-a8e1-3d3dc0be8d91"
}
```

### Example Success Response

```json
{

      "Kinh nghiệm 3 năm phát triển Backend trùng khớp với yêu cầu của JD.",
      "Trình độ học vấn đáp ứng yêu cầu."
    ],
    "recommendations": [
      "Bổ sung các chứng chỉ hoặc dự án thực tế sử dụng Docker và Redis để nâng cao khả năng cạnh tranh."
    ]
  },
  "meta": {},
  "correlationId": "5f1c0d68-9a3f-4c85-bf50-4a7c17c1e2af"
```

### Title & Summary

Truy vấn kết quả phân tích AI (`AI_MATCH_RESULT`) đã được lưu trữ cho một đơn ứng tuyển cụ thể.

```http
GET /api/v1/ai/applications/{applicationId}/match-result
```

Nhà tuyển dụng sở hữu JD hoặc Ứng viên nộp đơn ứng tuyển đó.

<summary><strong>API 5: Refresh Job Recommendations</strong></summary>

### Title & Summary

**Yêu cầu làm mới danh sách việc làm gợi ý thông minh**

Kích hoạt lại pipeline AI để tái tính toán và cập nhật toàn bộ bản ghi `JOB_RECOMMENDATION` cho Ứng viên dựa trên tất cả các phiên bản CV hiện tại (`CV_EMBEDDING`). Endpoint này hữu ích khi Ứng viên vừa cập nhật CV và muốn nhận gợi ý mới nhất mà không cần chờ chu kỳ định kỳ của hệ thống.

### Method & Path

```http
POST /api/v1/ai/recommendations/refresh
```

### Authentication & Authorization

Chỉ Ứng viên (`Candidate`) với Access Token hợp lệ.

### Headers

`Authorization`, `Content-Type: application/json` và `X-Correlation-ID` UUID là bắt buộc.

### Request Parameters / Body

Không có body. Hệ thống tự động lấy `candidate_id` từ Access Token.

### Response Status Codes

`202` Accepted — yêu cầu được nhận, AI pipeline đang xử lý bất đồng bộ; `401` token sai; `403` không phải Candidate; `409` đang có pipeline chạy cho user này (cooldown chưa hết); `503` AI bận (`AI_SERVICE_UNAVAILABLE`).

### Business Rules

- Hệ thống áp dụng **cooldown tối thiểu 5 phút** giữa hai lần refresh liên tiếp. Nếu vi phạm, trả về `409` với `code: REFRESH_COOLDOWN_ACTIVE`.
- Kết quả cũ (`JOB_RECOMMENDATION`) không bị xóa ngay; chỉ bị ghi đè khi pipeline hoàn tất.
- Nếu Ứng viên chưa có CV nào hoặc chưa có `CV_EMBEDDING`, trả về `422` với `code: NO_CV_EMBEDDING_FOUND`.

### Example Success Response

```json
{
  "data": {
    "status": "PROCESSING",
    "message": "Yêu cầu làm mới gợi ý việc làm đã được tiếp nhận. Kết quả sẽ sẵn sàng trong vài phút.",
    "estimatedCompletionSeconds": 30
  },
  "meta": {},
  "correlationId": "5f1c0d68-9a3f-4c85-bf50-4a7c17c1e2af"
}
```

### Example Error Response (Cooldown Active)

```json
{
  "error": {
    "code": "REFRESH_COOLDOWN_ACTIVE",
    "message": "Bạn vừa yêu cầu làm mới gợi ý. Vui lòng thử lại sau 5 phút.",
    "details": [
      { "field": "cooldownRemainingSeconds", "value": 243 }
    ]
  },
  "correlationId": "5f1c0d68-9a3f-4c85-bf50-4a7c17c1e2af"
}
```
