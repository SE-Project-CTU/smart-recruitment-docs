# Recruitment & Application API

## Group Summary

Quản lý `JOB_POSTING`, `INDUSTRY_GROUP`, `INDUSTRY`, `JOB_INDUSTRY`, `LOCATION`, `APPLICATION` và `APPLICATION_STATUS_HISTORY`.

## Planned API Scope

- Tạo, cập nhật, đóng và dừng nhận hồ sơ tin tuyển dụng.
- Tìm kiếm và lọc việc làm.
- Quản lý ngành nghề, địa điểm được dùng làm tiêu chí tìm kiếm.
- Ứng tuyển bằng CV version hoặc file PDF, kèm cover letter.
- Chống ứng tuyển trùng lặp.
- Theo dõi lịch sử ứng tuyển.
- Nhà tuyển dụng xem hồ sơ và cập nhật trạng thái ứng viên.

> Endpoint chi tiết sẽ được bổ sung theo cùng structure trong `README.md`.
